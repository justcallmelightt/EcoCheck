# 검증 결과 — 2026-10-23 (한국 시간)

## 이후 확인된 로컬 설정 상태

- 실제 개발 DB에 전용 앱 계정으로 접속하고 두 테이블을 조회하는 데 성공했습니다.
- Gemini 키를 사용한 모델 조회는 HTTP 200이었으나 생성 요청은 시간 초과로 미완료입니다.
- 네이버 키는 미설정 상태입니다. 실제 키·DB 계정 비밀번호는 저장소에 포함하지 않습니다.
- 아래의 키 미발급·DB 미설정 표시는 초기 검증 당시의 기록입니다.

## 통과한 항목

- JDK 21에서 Maven package 성공, 소스는 Java 17 대상으로 컴파일.
- HTTP 통합 테스트 9개: **모두 통과**.
- 실제 MySQL 8.0 JDBC 통합 테스트 1개: **통과**.
- 합계 **10개 실행 / 실패 0 / 오류 0 / 건너뜀 0**.
- 공식 서울시 XLSX → JSON: **6,849개 변환, 주소 누락 2개 제외**.
- 별도 MySQL 테스트 DB에 공식 변환 데이터 **6,849개 실제 적재 성공**.
- SQL 조회 결과 **imported_rows=6849 / located_rows=0**. 좌표가 없음을 그대로 보존함.
- CLI API 검사: database=PASS, Gemini/Naver=SKIPPED(키 미발급).
- 사용자의 실제 EcoCheck 폴더에 적용 후 JAR 시작 확인: `/api/v1/categories` HTTP 200, 5개 반환.
- 적용된 폴더의 `/health`는 HTTP 503, database=unavailable, Gemini/Naver 설정=false. 사용자 DB 계정·테이블·키가 아직 준비되지 않았음을 정확히 반환함.

HTTP 테스트는 실제 로컬 EcoCheck HTTP 서버와 로컬 공급자 대역 HTTP 서버를 연결해 실행했습니다. Gemini와 네이버 실제 서비스에 접속한 테스트와 구분해야 합니다.

검증한 동작:

1. 사진 입력→Gemini 형태의 요청→응답 해석→확인 후 저장→기록 조회→삭제.
2. 같은 분석 ID 재저장 시 중복 방지.
3. 다른 기기 토큰의 결과/기록 접근 및 삭제 방지.
4. 미확정 재질 저장 차단, 사용자 확인 없는 저장 차단.
5. 잘못된 이미지·JSON·페이지·경로·HTTP 방식 거절.
6. 지도 좌표 범위/NaN 검사, 거리 계산과 반경 밖 항목 제외.
7. 외부 429/403 및 잘못된 AI 분류 처리.
8. API 키 없음이 성공으로 표시되지 않는지 검사.
9. DB 불가 시 health=503 반환.
10. 실제 DB에 한국어 기록 저장, 새 Repository에서 조회, 기기 분리, 중복 방지, 삭제.

DB 검증은 기존 Windows MySQL 서비스와 별개의 임시 data 디렉터리, 127.0.0.1 전용 포트를 사용했습니다. 기존 DB/사용자/서비스는 수정하지 않았습니다. 테스트 서버는 종료했습니다. 사용자의 실제 Workbench 연결 계정으로 접속한 검증은 아닙니다.

## 다시 실행하기

`mvnw.cmd test`는 별도 테스트 DB 환경변수가 없으면 DB 테스트 1개를 건너뜁니다. 이는 이번 실제 DB 검증 결과와 다릅니다. DB까지 재검증하려면 SETUP.md의 전용 ecocheck_test 설정을 사용하세요.

자동 테스트 원본은 `src/test/java/kr/ecocheck`, Maven 상세 결과는 `target/surefire-reports`에 있습니다.
